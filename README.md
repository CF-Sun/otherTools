# iPAS AI 應用規劃師（中級）自學站

一個**純靜態、零相依、可離線使用**的自學網站，目標是通過經濟部產業人才能力鑑定（iPAS）**AI 應用規劃師（中級）**。

- 考綱依據官方《AI 應用規劃師能力鑑定 評鑑內容範圍參考》**115.06 版**，逐項對應 L21／L22／L23 共 **34 個評鑑內容**。
- 內容為**原創**的自學輔助教材，**不是官方教材，也不是歷屆考古題**。官方明確表示實際考題不限於所列範圍，請務必搭配官方資源（見文末）。

## 考試結構（以官方簡章為準）

| 科目 | 代碼 | 說明 |
|---|---|---|
| 科目一 | **L21 人工智慧技術應用與規劃** | **必考** |
| 科目二 | **L22 大數據處理分析與應用** | 與科目三擇一（或都考） |
| 科目三 | **L23 機器學習技術與應用** | 與科目二擇一（或都考） |

單選題、電腦化測驗，每科 100 分，通常 70 分及格。L22／L23 的試題含 **Python 程式題**（基本語法、程式邏輯判斷、程式片段解析）。題數、作答時間、梯次日期請以 iPAS 官網公告的簡章為準。

## 功能

| 功能 | 說明 |
|---|---|
| **考綱地圖** | 三科 × 主題 × 34 個評鑑內容，顯示筆記已讀與題目掌握度 |
| **筆記** | 每個評鑑內容一份：官方備註、考點、比較表、公式、Python 範例、易錯陷阱 |
| **題庫練習** | 427 題，可依科目／單元／難度／狀態篩選；作答後立即顯示詳解；鍵盤 1–4／A–D 作答 |
| **模擬考** | 限時、交卷後才公布答案；題號導覽、標記待檢查；成績含各主題表現與逐題檢討；重新整理不會丟失進行中的考試 |
| **名詞卡** | 224 張，Leitner 間隔重複（忘了／模糊／記得），每日新卡上限可調 |
| **錯題本** | 答錯的題目自動收錄，連續答對 2 次後移出 |
| **速查表** | 18 份：評估指標、檢定選擇、分佈、縮放、儲存架構、隱私法規、優化器、參數量計算、演算法比較、Python 讀程式陷阱… |
| **學習計畫** | 依考試日期與選考科目自動排程（學習 → 練習 → 衝刺），可勾選、可重新排程 |
| **其他** | 全站搜尋、亮／暗色、手機版、進度匯出／匯入（JSON） |

進度只存在**瀏覽器的 localStorage**，換裝置或清除網站資料前請先到「設定」匯出備份。

## 使用方式

### 直接開啟（最簡單）

沒有建置步驟、沒有外部連線。下載專案後雙擊 `index.html` 即可使用。

### 本機伺服器

```bash
npm run serve        # 或：npx http-server -p 8080
```

### 部署到 GitHub Pages

專案已附 `.github/workflows/pages.yml`：合併到 `main` 後，到 **Settings → Pages → Source** 選擇 **GitHub Actions**，之後每次推送到 `main` 會先跑資料驗證，通過才部署。

## 專案結構

```
index.html                 入口（依序載入下列 script）
```

## 品質控管

題目與數值是這個專案最容易出錯、也最影響學習成效的部分，因此做了以下處理：

- **數值題與程式題逐一實際執行驗證**：統計量、混淆矩陣指標、參數量、卷積輸出尺寸、PCA／標準化／sklearn 輸出等，都用 Python（NumPy／pandas／scikit-learn／SciPy）重算過；PySpark／Keras／PyTorch 題則以語意與公式推演。
- **正確答案位置平衡**：A／B／C／D 各約 25%；作答時預設還會再隨機打亂選項順序。
- **消除猜題線索**：經檢查，初稿存在「正確選項特別長」（中位數為誘答的 2.6 倍）與「誘答含一定／完全／只能等絕對語氣」兩種偏差，已逐題改寫誘答；現在長度比中位數約 1.13，絕對語氣詞在正確選項與誘答中的比例相當。`tests/validate-data.mjs` 會持續檢查這些指標。
- **詳解不使用 A／B／C／D 指涉選項**（選項會被打亂），驗證腳本會擋下。

```bash
npm run validate     # 結構、考綱覆蓋、猜題線索（不需要任何套件）
npm run test:smoke   # 瀏覽器煙霧測試（需要 playwright 與 Chromium）
```

## 新增或修改內容

- **題目／名詞卡**：用 `Q(項目代碼, 難度 1–3, 題幹, [四個選項], 正確索引, 詳解, { code, lang })`、`C(項目代碼, 正面, 背面)`。進度以「項目代碼 + 出現順序」的 id 儲存，所以**請只在各檔案尾端附加**，不要插入或重排既有題目。
- **筆記**：`N(項目代碼, String.raw\`...\`)`，文字中的反引號以 `§` 代替；支援 `##` 標題、清單、表格、程式區塊、`> [!exam|tip|warn|trap]` 提示框、`**粗體**`、`==重點==`。表格儲存格內不要使用 `|`。
- 改完請執行 `npm run validate`。
